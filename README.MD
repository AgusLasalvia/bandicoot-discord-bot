# 🦘 Bandicoot Discord Bot

A feature-rich and extensible Discord bot written in Python by AgusLasalvia! 🎉

## 🚀 Features

- Built with Python
- Uses the Discord library
- Easily extendable with your own commands and events

## 📦 Installation

1. Clone the repository:
   git clone https://github.com/AgusLasalvia/bandicoot-discord-bot.git
   cd bandicoot-discord-bot

2. Install dependencies:
   pip3 install -r requirements.txt
  
3. Create a .env file from the example:
   touch .env

4. Fill in your .env file:
   DISCORD_TOKEN=your-discord-token

5. Start the bot:
   python3 main.py

## ⚙️ Usage

- Default prefix is !
- Use !help to see available commands



## 🌐 Deployment

You can deploy this bot to:
- Railway
- Render
- Replit
- Heroku
- Or your own VPS

Make sure to configure environment variables like DISCORD_TOKEN.
